# 필기 튜터 서버

FastAPI 서버가 iPad의 필기 이미지와 주변 획을 받아 BAZE 비전 모델로 보낸다. 모델의 응답은 서버에서 허용된 액션과 관찰 범위의 대상 ID로 검증한다. 앱은 현재 노트와 필기 revision을 다시 확인한다. 사용자가 자동 판서를 켠 경우 검증된 응답을 튜터 레이어에 바로 기록하며, 직접 질문한 응답은 제안을 확인한 뒤 적용한다.

`write` 판서는 `\frac{1}{2}`, `\sqrt{x}`, `x^{2}`, `H_{2}O`를 분수선·근호·첨자로 배치한다. 기존에 저장한 수식과 새 수식은 같은 렌더러로 그리고 화면과 PDF 내보내기에 같은 배치를 사용한다. 긴 수식은 기호 단위로 줄을 나누며, 한 줄보다 긴 분수는 읽을 수 있는 괄호와 슬래시 표기로 표시한다.

## 연결과 데이터

서버 환경에 `BAZE_API_KEY`, 조직이 허용한 비전 모델의 `BAZE_MODEL`, 별도로 발급한 `REEDLE_CLIENT_TOKEN`을 제공한다. 백엔드만 BAZE 키를 읽는다. 로컬 실행은 `uv run --directory server uvicorn reedle_server.app:app --host 127.0.0.1 --port 8000`을 사용한다. iPad에서 연결하려면 이 서버를 TLS 프록시 뒤에 두고 앱에 HTTPS 주소와 접속 토큰을 등록한다. [서버 설정](../server/README.md) · [BAZE 모델 조회](https://docs.mindlogic.ai/docs/general/api-gateway/getting-started/models)

앱은 전송을 켜기 전에는 네트워크에 필기를 보내지 않는다. 손을 뗀 뒤 새 획 주변의 보이는 부분을 최대 640×480 월드 포인트로 자른다. 해당 영역에 PDF가 있으면 원본 문제 위에 학생 잉크를 합쳐 캡처한다. PNG 최대 512 KiB, 최근 획 128개, 같은 노트의 겹치는 영역에서 이전 인식 기록 최대 3개를 보낸다. 관찰이 끝나면 다음 수정부터 새 영역을 모으며, 자동 제안에서 직전에 관찰한 이미지와 대상이 같으면 요청을 건너뛴다. 연결 토큰은 Keychain에 저장한다. 자동 제안을 끄면 **이 영역 질문하기**를 누를 때만 전송한다. 저장이나 도구 조작이 튜터 서버 가용성에 의존하지 않는다.

**튜터 → 조용히 모드**로 전환하면 진행 중 요청을 취소하고 미승인 제안을 닫는다. 직접 질문한 응답만 캔버스에 표시한다. **튜터 사용 중지**는 직접 질문까지 중단하며, 다시 시작하려면 연결 설정에서 튜터 서비스를 켠다.

앞서 힌트를 제안한 것과 같은 풀이를 다시 인식하면 서버가 새 판서를 보류한다. 자동 모드에서는 pen-up와 대기 후 신뢰도 기준을 넘긴 판서를 별도 승인 없이 튜터 레이어에 표시한다. 이미 적용한 판서는 다시 승인 제안으로 띄우지 않는다. 직접 질문한 경우 수식 옆의 **판서 제안 보기**로 제안을 열고 적용한다. 앞선 힌트에 이어 새로운 답을 읽었을 때 신뢰도 기준을 넘긴 후속 피드백은 해당 필기 옆과 **최근 인식 결과**에 표시된다. 후속 피드백은 현재 필기 revision과 같은 동안 다시 열 수 있다. 연습문제의 분야별 통계는 별도 로컬 테이블에 둔다.

**튜터 기록 삭제**는 현재 노트의 판서와 인식 기록을 지우고, 삭제 이전의 응답이 다시 저장되는 것을 막는다. **보기 → 노트 백업 내보내기**는 해당 시점에 노트에 들어 있는 필기·판서·인식 기록을 SQLite 파일로 만든다. 이전 백업은 저장한 위치에서 관리한다.

게이트웨이는 요청 이미지와 원문을 파일에 저장하지 않는다. 중복 방지용 응답 캐시는 기본 5분이며 운영자가 비활성화할 수 있다. 마지막 요청 연결이 끊어지면 게이트웨이가 남은 처리를 취소한다. BAZE에 도달한 호출의 비용과 보관은 적용되는 서비스 정책을 따른다. [게이트웨이 환경 설정](../server/README.md) · [BAZE 개인정보처리방침](https://baze.co/legal/privacy/)

## 검증

- `python3 tools/test_core.py`는 WSL에서 월드 좌표, 저장 복구, 관찰 범위, 오래된 응답, 중복 판서, 노트별 이력을 검증한다.
- `uv run --directory server --locked pytest -q`는 잘못된 인증과 이미지, 낮은 인식 신뢰도, 허용되지 않는 응답, 429·5xx 복구, 일간 사용 제한을 검사한다.
- Swift와 SQLite 헤더가 있는 Linux에서 `uv run --project server --locked python tools/test_tutor_round_trip.py`를 실행하면 Swift 클라이언트가 임시 FastAPI 서버에 실제 HTTP 요청을 보낸다. 테스트 비전 응답으로 `2+2=5`에서 `2+2=4`로 이어지는 흐름을 확인한다. 연결 중단, 오프라인, 429와 5xx를 발생시켜도 필기 데이터가 계속 저장되는지 검증한다.
- Xcode의 `python3 tools/test_ipad.py`는 앱에서 캡처한 PencilKit 기반 PNG가 화면 범위와 크기 제한을 지키는지 확인한다.

2026년 11월 22일 GitHub macOS에서 iPad 단위 테스트 74개·UI 테스트 3개가 실패·건너뜀 없이 통과했다. 실제 TutorAssistant의 pen-up 예약과 BAZE HTTPS/SSE로 승인 없는 주석·질문, 학생의 4 정정, 후속 피드백과 복원을 확인했다. PDF 저장 검사는 20페이지 각각의 학생 획과 튜터 대상 ID를 원본 노트와 백업에서 다시 읽어 대조한다. iPad 검사에서는 PDF 원문과 학생 잉크를 함께 캡처하고, 내보낸 20페이지에서 원문·학생 필기·튜터 밑줄·수식을 이미지로 대조했다. 튜터 판서는 화면과 PDF에 같은 Core Graphics 경로와 글리프 배치를 사용한다.
