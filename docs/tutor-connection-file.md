# 튜터 연결 파일

앱의 **튜터 연결 → 연결 파일에서 불러오기**에서 서버가 내보낸 JSON을 선택한다. 서버 주소와 별도의 앱 접속 토큰이 설정 초안에 들어간다. 불러온 직후 서비스와 자동 판서는 꺼져 있다. 주소를 확인하고 사용할 모드를 선택한 뒤 **저장**해야 적용된다. 파일 선택만으로 전송하거나 현재 저장된 연결을 바꾸지 않는다.

파일은 `format`, `version`, `server`, `access_token` 네 필드만 받는다. 형식은 [자격증명 없는 예시](../examples/tutor-connection.example.json)를 참고한다. 최대 8 KiB이며 HTTPS 주소, 512바이트 이하의 공백 없는 ASCII 앱 토큰이 필요하다. 공급자 키 필드와 `baze_` 토큰은 거부한다. BAZE 키는 서버 계정에만 둔다.

## 서버에서 내보내기

Windows 서버 계정에 `REEDLE_CLIENT_TOKEN`을 설정하거나 이 개발 계정의 기존 암호화 설정을 사용한다. 실제 iPad에서 접근할 수 있는 HTTPS 튜터 서버 주소를 지정한다.

```powershell
.\Export-Reedle-Connection.cmd -Server 'https://your-tutor.example'
```

위 주소는 자리표시자다. 실제 배포된 주소로 바꿔야 한다. 기본 저장 위치는 `%LOCALAPPDATA%\ReedlesCanvas\tutor-connection.json`이며 현재 Windows 계정만 읽을 수 있도록 권한을 제한한다. 기존 파일은 `-Replace`를 지정해야 덮어쓴다. `-OutputPath`로 별도 경로를 지정할 수 있지만 저장소 안에는 내보낼 수 없다. 토큰은 명령줄 인자가 아닌 환경변수에서만 읽으며 출력하지 않는다.

다른 서버에서는 `python tools/export_tutor_connection.py --server https://your-tutor.example`를 사용한다. POSIX 파일 권한은 0600이다. 완성된 파일만 원자적으로 공개하며 다른 계정에 공유되는 공개 소스 ZIP에는 포함하지 않는다.

연결 파일에는 앱 접속 권한이 들어 있으므로 본인의 기기로 비공개 전송한다. GitHub, 공개 채팅 또는 공용 파일 저장소에 올리지 않는다. 가져온 뒤 전달용 복사본을 정리하고, 파일이 노출되면 서버의 앱 토큰을 교체한다.

## HTTPS 배포에 필요한 것

현재 서버 실행 도구는 준비되어 있으나 이 앱용 공개 HTTPS 주소는 아직 확정되지 않았다. BAZE 공급자 API 주소를 앱 서버 주소로 대신 입력할 수 없다. [서버 실행 안내](../server/README.md)에 따라 아래를 준비한다.

1. 서버 프로세스를 실행할 Windows 또는 Linux 호스트.
2. iPad에서 접속 가능한 도메인과 유효한 HTTPS 인증서 또는 기존 HTTPS 리버스 프록시.
3. `/v1/tutor/observe` 요청과 SSE 응답을 전달하는 프록시 설정. 스트림 버퍼링을 끄고 요청 제한·인증과 기존 서버 제한을 유지한다.

이 주소가 정해지면 해당 서버 계정에서 연결 파일을 내보내 사용할 수 있다. 이번 변경에서는 서버를 공개하지 않았고 실제 토큰 파일도 생성하지 않았다. 사용자의 지시에 따라 회귀·실기기 시험을 보류하며 앱 컴파일만 수행한다. 기존 실기기 부하 크래시의 해결을 의미하지 않는다.
