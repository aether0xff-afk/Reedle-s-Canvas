# 일반 앱 미리보기

2026년 11월 23일 사용자 지시에 따라 실기기 시험과 충돌 기록 수집 요청을 보류하고 실사용 화면 개발을 이어간다. 이 미리보기는 `ReedlesCanvasApp`으로 시작하는 일반 앱 소스다. 1만 획 자동 시험·90초/10분 버튼과 DeviceLab 소스는 포함하지 않는다.

## 사용하기

`ReedlesCanvas-App.swiftpm.zip`을 iPad 파일 앱으로 옮기고 압축을 푼 뒤 `ReedlesCanvas.swiftpm`을 Swift Playgrounds에서 연다. 실행하면 빈 캔버스에서 바로 필기할 수 있다. 시작 안내는 펜이나 손가락 입력을 가로채지 않으며 필기·PDF·연습문제가 있으면 표시하지 않는다.

상단 상태 영역의 **튜터 연결**에서 기존 HTTPS 튜터 서버 주소와 서버 접속 토큰을 설정한다. 공급자 BAZE 키는 앱에 입력하지 않는다. 자동 판서는 사용자가 기존 연결 설정에서 켰을 때만 동작한다. 읽기·작성·제안·요청 오류가 캔버스 밖의 같은 상태 영역에 표시되며 멈춤·제안 보기·질문·설정으로 바로 이어진다. 저장 실패 시에는 필기를 유지한다는 안내와 다시 저장 동작을 표시한다.

추가된 **연결 파일에서 불러오기**는 HTTPS 주소와 별도 앱 토큰을 설정 초안으로 가져온다. 사용 모드를 선택하고 저장해야 적용되며, 파일을 선택한 시점에는 전송하지 않는다. [비공개 연결 파일 내보내기](tutor-connection-file.md)

자료, PDF 내보내기, 연습문제, 튜터 기록과 원본/AI 레이어 제어는 기존 메뉴에서 사용한다. 서버 실행·보관 정책은 [튜터 서버 안내](tutor-gateway.md)를 따른다.

Windows 서버는 저장소 루트의 `Start-Reedle-Server.cmd`로 실행할 수 있다. 이 개발 계정에 저장한 암호화 자격증명을 재사용하며, 기본 루프백 서버를 외부 HTTPS 프록시 뒤에 두거나 인증서를 지정해 TLS로 실행한다. iPad에 연결할 HTTPS 주소와 별도 접속 토큰 설정은 필요하다. [서버 실행 옵션](../server/README.md)

## 이번 변경의 확인 범위

회귀 테스트와 실기기 시험은 실행하지 않는다. 아래 기존 화면 미리보기 이후의 연결 파일 변경은 Mac에서 컴파일만 수행하며 앱을 실행하거나 새 화면을 캡처하지 않는다. 이는 기능·성능 테스트 통과를 의미하지 않는다. 빌드 결과와 소스 버전은 `ReedlesCanvas-App-manifest.json` 및 미리보기 artifact의 `preview.json`에 기록한다.

앞서 보고된 실기기 자동 부하 크래시는 원인이 확정되지 않았고 해결된 것으로 표시하지 않는다. AET-49는 검증 보류 상태이며 원래 작업 기준 진행률은 22/23개다. 새 화면과 배포본 개발은 이 검증을 기다리지 않고 진행한다.
