# Reedle’s Canvas

iPadOS에서 학생과 AI가 같은 캔버스에 필기하는 학습 도구입니다. 현재 앱에서는 Apple Pencil 필기, 월드 좌표 기반 이동·확대, 획 편집, 로컬 저장을 사용할 수 있습니다. **튜터 → 판서 예제 열기**에서 예제 풀이에 대한 튜터 답변을 미리 보고 적용할 수 있습니다.

2026년 11월 23일부터 실기기 시험은 사용자 지시에 따라 보류하고 일반 앱 화면과 배포본을 정리합니다. 빈 캔버스 안내와 튜터 상태 영역을 추가했습니다. [일반 앱 미리보기](docs/app-preview.md)는 시험 버튼이 없는 Swift Playgrounds 앱 소스이며, 이번 변경은 빌드·화면 캡처만 진행합니다. 기존 실기기 자동 부하 크래시는 미해결로 기록합니다.

Windows 튜터 서버는 저장소 루트의 `Start-Reedle-Server.cmd`로 실행합니다. 저장된 서버 계정 설정을 읽고, 외부 직접 연결에는 TLS 인증서를 요구합니다. [서버 실행 옵션](server/README.md)

실제 iPad용 Release/arm64 바이너리는 [기기 빌드 안내](docs/ipad-build.md)에 따라 미서명 IPA로 생성할 수 있습니다. 기기 설치에는 별도 Apple 서명이 필요하며, 테스트는 실행하지 않습니다.

서버 주소와 앱 접속 토큰은 [연결 파일](docs/tutor-connection-file.md)로 가져올 수 있습니다. 서버에서 `Export-Reedle-Connection.cmd -Server 'https://실제서버주소'`로 비공개 파일을 내보내고 앱의 튜터 연결 설정에서 선택합니다. 실제 HTTPS 서버 주소는 별도로 필요합니다. 이 추가 변경은 앱 실행·회귀 시험 없이 컴파일만 확인합니다.

## 캔버스와 저장

Apple Pencil로 필기하고 손가락으로 이동합니다. 시스템 도구 선택기에서 펜·지우개·올가미를 고릅니다. 두 번 탭하면 탭 위치를 기준으로 확대·축소하고, **보기 → 현재 위치 기억**으로 같은 세션에서 다시 찾아올 수 있습니다. 상단 화살표는 획 추가·삭제·이동을 실행 취소하거나 다시 실행합니다.

노트는 Documents의 `drawing.sqlite`에 획 UUID, 월드 범위, 그리기 순서와 PencilKit 데이터를 보관합니다. 카메라와 변경된 획을 트랜잭션으로 저장하고, 화면 주위의 획을 공간 인덱스로 조회합니다. 저장 파일이 잠기면 앱이 기록을 들고 있다가 잠금이 풀릴 때까지 제한된 횟수로 재시도합니다. 이전 버전의 `drawing.pkdrawing`은 첫 마이그레이션에서 읽고 원본을 보존합니다. **보기 → 노트 백업 내보내기**로 독립된 SQLite 스냅샷을 저장할 수 있습니다.

Xcode와 iOS Simulator 런타임이 있는 Mac에서 `brew install xcodegen` 후 `python3 tools/test_ipad.py`를 실행하면 iPad 시뮬레이터를 선택해 단위 테스트와 UI 테스트를 실행합니다. 결과와 UI 캡처는 `.build/ipad-tests/`의 `.xcresult`에 저장됩니다. GitHub Actions의 `iPad app build`도 같은 명령을 실행합니다.

복원 테스트는 펜과 마커를 섞은 합성 1,000획을 파일에 저장하고 새 문서에서 엽니다. 획 순서와 위치, 색, 굵기, 필압, 기울기, 시각을 대조합니다. 별도의 테스트로 손상 파일의 원본 보존과 저장 실패 후 캔버스를 다시 열어 재저장하는 경로를 확인합니다.

RDP로 개발 중이면 `python tools/package_playground.py`로 iPad에서 열 수 있는 앱 프로젝트를 만드세요. M1 통합 시험에는 `python tools/package_playground.py --m1-checkpoint --output .build/ReedlesCanvas-M1.zip`을 사용합니다. 이 패키지는 별도 디렉터리에 1만 획을 한 번 생성하며 앱과 같은 편집·저장 코드를 실행합니다. [실기기 검증 절차](docs/ipad-device-spike.md)

iPad가 별도 Windows 노트북에 연결돼 있으면 `python tools/package_device_lab.py`로 노트북 전달용 ZIP을 만듭니다. iPad의 Swift Playgrounds에서 독립된 1만 획 자동 시험을 실행하고 노트북에서 결과 JSON·선택적 USB 성능 로그를 모읍니다. [노트북에서 실기기 시험하기](docs/laptop-device-tests.md)

Linux와 Windows의 WSL에서는 Swift와 `libsqlite3-dev`를 설치한 뒤 `python3 tools/test_core.py`로 카메라, 획 식별, 저장 복구, 튜터 데이터와 배치를 검증합니다. 저장 복구 시험은 미확정 변경을 디스크에 쓰는 보조 프로세스를 강제로 종료한 뒤 마지막 확정 획·카메라·튜터 레이어를 다시 읽습니다. PencilKit UI는 Xcode iPad Simulator에서 실행하며, 실제 Pencil 지연과 프레임률은 기기 계측 대상입니다.

## 튜터 판서

판서 예제는 별도 노트의 `2 + 2 = 5`에서 마지막 값에 표시를 하고 다시 계산할 질문을 제안합니다. 학생이 **판서 적용**을 누르면 표시와 문구가 나타납니다. **튜터 판서 표시**와 **마지막 튜터 판서 되돌리기**는 튜터 객체에만 적용됩니다. **현재 영역의 판서**에서 겹침 때문에 캔버스에 놓지 못한 제안도 읽을 수 있습니다. 이 예제는 내장 답변으로 동작합니다.

SQLite v5는 기존 노트를 열어 튜터 판서, 필기 revision, 최근 인식 기록, PDF 자료와 연습 기록을 보관합니다. 제안 생성 뒤 학생이 필기를 바꾸면 제안을 다시 받아야 합니다. 팬·줌과 레이어 표시 설정은 필기 revision을 바꾸지 않습니다.

**튜터 → 튜터 연결 설정**에 FastAPI 서버의 HTTPS 주소와 접속 토큰을 저장하면 실제 필기 질문을 전송할 수 있습니다. **필기 후 자동 판서**를 켜면 필기를 마친 뒤 검증된 표시와 질문이 별도 승인 없이 튜터 레이어에 나타납니다. 직접 질문한 판서는 제안을 확인한 뒤 적용합니다. 필기가 바뀌거나 앱이 백그라운드로 가면 진행 중인 요청을 중단합니다. [서버와 자동 검증](docs/tutor-gateway.md)

**튜터 → 조용히 모드**는 직접 질문할 때만 전송하며 **튜터 사용 중지**는 연결을 끕니다. 튜터 설정에서 자동 판서 민감도, 글씨 크기, 색상과 전송·보관 안내를 볼 수 있습니다. **튜터 기록 삭제**는 현재 노트의 인식 기록과 튜터 판서를 지우고 삭제 전에 시작한 응답의 적용을 막습니다. [필기 튜터 운영 안내](docs/tutor-gateway.md) · [iPad 설치와 서명](docs/ipad-device-spike.md)

## 연습문제와 자료

**연습** 메뉴에서 화면에 보이는 최근 풀이와 같은 분야의 새 문제를 그 풀이 주변에 배치할 수 있습니다. 덧셈, 일차방정식, 원자가 전자, 속력과 힘 등은 오프라인에서도 문제를 생성하고 답을 확인합니다. 힌트는 한 단계씩 열립니다. 도움 없이 두 문제를 연속으로 풀면 난이도가 올라가고, 오답을 낸 문제마다 한 단계 내려갑니다. 사용한 힌트와 재시도 뒤 맞힌 문제는 분야별 학습 기록에서 확인할 수 있습니다.

**자료** 메뉴에서 PDF와 HTTPS 자료 링크를 노트에 추가합니다. 검색에서 PDF 텍스트와 저장된 인식 기록을 찾아 캔버스의 해당 위치로 이동할 수 있습니다. 내보내기에는 PDF 원본 위의 학생 필기와 보이는 튜터 판서가 포함됩니다.

60개 합성 필기 입력과 자동 채점으로 수학, 루이스 구조, 물리 도식을 비교할 수 있습니다. [평가 데이터와 자동 검증](docs/evaluation.md)

2026년 11월 22일 Mac의 iPad 시뮬레이터 검사 80개와 서버 검사 66개가 통과했습니다. [실제 결과 화면](docs/native-results.md) · [23개 작업의 완료 조건 대조](docs/completion-audit.md) · [판서 표현 비교](docs/tutor-rendering.md). 현재 22/23개 완료이며, AET-49의 실제 기기 지연·프레임·메모리·배터리 계측과 기기 창 관리 확인이 남았습니다.

## 첫 수직 슬라이스

1. Apple Pencil 획을 월드 좌표의 `userInk`로 저장하고 다시 엽니다.
2. 변경 영역만 AI에 관찰시킵니다. AI는 대상 객체와 의도를 반환합니다.
3. 앱이 충돌 없는 위치를 결정해 별도 `aiOverlay`에 판서합니다.
4. 학생이 답을 고치면 새 revision을 관찰하고 이전 주석과 연결합니다.

`userInk`는 학생 편집 명령만 변경할 수 있습니다. AI의 응답은 좌표, 삭제, 수정 명령을 포함하지 않습니다. 응답의 대상 ID와 관찰 revision은 앱에서 다시 확인해야 합니다.

## 계약 확인

```bash
python -m pip install jsonschema
python tools/validate_contracts.py
```

계약과 미검증 기술 선택은 [ADR-0001](docs/ADR-0001-canvas-boundary.md)에 있습니다. iPad 빌드, PencilKit 저장, BAZE 이미지 API는 각각 Linear의 AET-31, AET-32, AET-33에서 실제 기기로 확인합니다.
